## 0. 结论先行

首版只做一件事：**一个打开就能用、不丢状态、能正确倒计时的番茄钟**。

- P0 可上线范围：三阶段倒计时（专注 25 / 短休 5 / 长休 15）、开始暂停重置、自动流转、番茄计数、刷新后恢复、手机可用、子路径部署不 404。
- 明确不做：账号、云同步、任务清单、统计报表、系统通知。
- 硬约束：**不得影响线上现有站点任何功能**。

## 1. 背景与目标

### 1.1 背景

用户需要一个自用的番茄工作法计时器。现有站点 hk.hsddns.com 上已有其他服务，路径 `/pomodoro-focus` 目前为空（404），可安全挂载一个独立单页应用。

### 1.2 目标

| 序号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 打开即用，无需注册、无首屏等待 | 首屏可交互 < 2s（含缓存）；无登录流程 |
| G2 | 计时可信，后台切回不跑偏 | 离开 5 分钟返回，剩余时间误差 ≤ 2s |
| G3 | 状态不丢，刷新/误关可恢复 | 运行中刷新，剩余时间接续、状态一致 |
| G4 | 手机单手可操作 | 360×640 视口下按钮可点、计时器可读 |
| G5 | 零影响现有站点 | 根路径与其他 location 行为与上线前一致 |

### 1.3 目标用户与核心场景

- 用户：单人自用（本人），无多账号概念。
- 场景 1（主）：工作中想专注 25 分钟，打开页面点「开始」，结束休息 5 分钟，循环 4 轮后长休。
- 场景 2：中途被打断，点「暂停」，回来点「继续」。
- 场景 3：手机上排队/通勤时打开同一地址使用。
- 场景 4：不小心刷新或关掉标签页，重新打开后接着计时。

## 3. 功能详述

### FR-01 计时器显示

- 页面中心为剩余时间，格式 `mm:ss`（如 `25:00`、`04:59`），只显示分秒，不显示毫秒。
- 计时器字号为页面最大视觉元素，手机上无需缩放即可读清。
- 当前阶段名称（专注 / 短休 / 长休）在计时器上方或下方明确显示，用户一眼能分辨当前状态。
- 剩余时间不出现负数、不跳秒、不卡住（见 AC-11）。

### FR-02 控制按钮

主按钮文案随状态变化，同一位置同一按钮，避免误点：

| 当前状态 | 主按钮 | 次按钮 |
|---|---|---|
| 未开始 | 开始 | 重置、跳过 |
| 运行中 | 暂停 | 重置、跳过 |
| 已暂停 | 继续 | 重置、跳过 |

- 「重置」：当前阶段回到完整时长，计时停止（状态=已暂停/未开始），**不清空已完成番茄数**。
- 「跳过」：直接结束当前阶段并进入下一阶段，**不计入番茄数**。
- 运行中按钮需有可用视觉反馈（hover / active / disabled 态清晰）。

### FR-03 阶段流转规则

状态机（唯一合法流转）：

```
专注 --(到 0)--> 第 1~3 个番茄：短休；第 4 个番茄：长休
短休 --(到 0)--> 专注
长休 --(到 0)--> 专注，且本轮计数归零
任意阶段 --(跳过)--> 下一阶段（专注→短休→专注…，跳过不计数）
```

- 进入新阶段后**不自动开始**，停在「未开始」等用户点开始（可避免离开时无意义空跑）。此条为产品决策，若需自动开始，改配置即可。
- 第 4 个番茄判定：本轮已完成专注数达到 4（即 `count % 4 === 0` 且 `count > 0`）。

### FR-04 番茄计数

- 显示 `已完成 / 长休间隔`，默认如 `2 / 4`。
- 仅在专注阶段自然倒计时到 0 时 +1；跳过、重置、退出均不计数。
- 长休结束后计数归零。

### FR-06 阶段结束提示

- FR-06a（P0，视觉）：阶段结束瞬间必须处于**可自证的「已结束」态**，面板五项同时成立且互不矛盾：
  - 阶段标签显示**刚结束的阶段**（「专注」/「短休息」/「长休息」），不得显示下一阶段
  - 大字计时器 `00:00`（不得显示下一阶段的满时长）
  - 状态文案「已结束」
  - 进度条 100%
  - 页面标题 `✓ {阶段}结束`（如 `✓ 专注结束`）
  - 附加：主按钮回到「开始」、番茄计数已 +1、有短暂高亮/闪烁等可见提示。
- 结束态是**独立停留态**：不自动进入下一阶段（除非设置里显式开启自动开始，默认关）；用户点「开始」后才进入下一阶段，阶段标签切换为下一阶段、并从其满时长起算。
- 禁止组合：同一面板不得出现「短休息 + 00:00 + 已结束」这类阶段名与结束态互斥的组合。
- FR-06b（P1，声音）：提供提示音，且必须有静音开关；**默认不播放，需用户首次点击「开始」后才允许出声**（浏览器自动播放策略），首次使用时若用户未开启声音不得报错。

### FR-07 时长设置（P1）

- 可设置：专注时长、短休时长、长休时长、长休间隔（几个番茄后长休）。
- 取值范围：时长 1–120 分钟整数；间隔 2–8 个。
- 默认值：25 / 5 / 15 / 4。
- **改值即存**：改动设置项后立即持久化到本机，无需点「保存」；刷新后设置不变。
- **不打断当前阶段**：运行中改时长，当前阶段的剩余时间与进度条**保持不变**（不跳变、不重置成新时长）；新时长从下一个新开始的阶段生效。
- 「恢复默认」：一键回到 25 / 5 / 15 / 4，立即持久化。

### FR-08 状态持久化

- 需持久化：当前阶段、是否在运行、剩余时间（或等价的可恢复信息）、已完成番茄数、设置项（P1）、静音开关（P1）。
- 刷新页面、关闭后重开浏览器、手机切后台被回收后再打开，均恢复到一致状态（见 AC-08）。
- 若持久化能力不可用（隐私模式、禁用本地存储）：页面必须**正常工作、不报错、不白屏**，仅退化为「刷新即丢失」（见 AC-09）。

### FR-09 响应式与可访问性

- 移动优先：360×640 可用，无横向滚动；平板与桌面内容居中，计时器不无限拉伸。
- 全功能可不依赖鼠标完成：Tab 可依次聚焦到按钮/设置项，Enter/Space 可触发；焦点可见。
- 文字与背景对比度足够（正文与关键信息 ≥ 4.5:1）。
- 尊重系统减少动效偏好（`prefers-reduced-motion`）时，闪烁类提示改为静态变化（P1）。

### FR-10 子路径部署

- 访问 `https://hk.hsddns.com/pomodoro-focus` 与 `https://hk.hsddns.com/pomodoro-focus/` 均能用；资源不得 404（不能依赖站点根路径的绝对引用）。
- 页面在 `/pomodoro-focus/` 下正确加载样式、脚本、图标，无控制台 404。
- 缓存策略由 Arch/Ops 定，但**升级后不得出现新旧资源混用导致的白屏**（须有版本化或合理缓存头）。

### FR-11 计时准确性

- 计时以真实经过时间为准，不因标签页后台、锁屏、设备休眠而少算或多算（见 AC-11）。
- 若休眠期间阶段已结束，返回页面时应已处于下一阶段（视觉提示可补），番茄数正确，不出现「一次性补跳多个阶段并乱转」的现象（最多前进到当前应处的阶段）。

### FR-12 页面标题（P1）

- 标签页标题显示 `剩余时间 · 阶段`，例如 `24:59 · 专注`；未开始时显示 `25:00 · 专注`。

## 4. 验收标准（Given-When-Then）

> 供 QA 直接转用例。所有用例默认在 `https://hk.hsddns.com/pomodoro-focus/` 上验证；本地开发验证可等价替换为本地地址加同一子路径前缀。
>
> **阶段名以实现文案为准**：`专注` / `短休息` / `长休息`（对应 `PHASE_LABEL`），断言按这三个字符串匹配。

**AC-01 首屏加载**
- Given 用户访问 `/pomodoro-focus/`
- When 页面加载完成
- Then 显示 `25:00`、阶段为「专注」、主按钮为「开始」、番茄计数 `0 / 4`，控制台无 JS 报错

**AC-02 开始与倒计时**
- Given 处于专注阶段未开始
- When 点击「开始」
- Then 主按钮变为「暂停」，倒计时开始递减；等待 3 秒后剩余时间在 24:56–24:58 之间

**AC-03 暂停与继续**
- Given 专注阶段运行中
- When 点击「暂停」，等待 5 秒，再点击「继续」
- Then 暂停期间数字不变；继续后从暂停时的剩余时间接着递减，不回退到整点

**AC-04 重置**
- Given 阶段运行中且剩余时间已减少
- When 点击「重置」
- Then 剩余时间回到当前阶段完整时长，主按钮为「开始」，已完成番茄数不变

**AC-05 专注结束进入「已结束」态，面板五项一致**
- Given 专注阶段剩余 2 秒且已完成番茄数 < 3
- When 倒计时到 0
- Then **同一时刻**五项同时成立：阶段标签「专注」、大字 `00:00`、状态文案「已结束」、进度条 100%、页面标题 `✓ 专注结束`
- And 阶段标签**不得**显示「短休息」（禁止「短休息 + 00:00 + 已结束」组合）
- And 主按钮为「开始」，番茄计数 +1，有可感知的视觉提示（闪烁/高亮）
- And 此时**不自动开始下一阶段**，页面保持在结束态

**AC-06 点「开始」才切到短休息 / 第 4 个番茄后进长休息**
- Given 已处于「已结束」态（阶段标签仍为「专注」）
- When 点击「开始」
- Then 阶段标签切为「短休息」、大字显示 `05:00`、状态「进行中」（点击即起表，不停在「就绪」）、进度条回到 0 并开始倒计时
- And 第 4 个番茄结束（已完成数达到长休间隔）后，结束态标签仍为「专注」、进度 100%、标题 `✓ 专注结束`；点「开始」后切为「长休息」并显示 `15:00`、状态「进行中」

**AC-07 长休结束计数归零**
- Given 长休阶段剩余 2 秒
- When 倒计时到 0
- Then 处于「已结束」态：阶段标签「长休息」、大字 `00:00`、状态「已结束」、进度 100%、标题 `✓ 长休息结束`
- And 番茄计数归零为 `0 / 4`
- And 点「开始」后阶段标签切为「专注」、大字显示 `25:00`

**AC-08 刷新后恢复**
- Given 专注阶段运行中、剩余约 20 分钟、番茄数 2
- When 刷新页面
- Then 阶段仍为「专注」、仍在运行、剩余时间与刷新前一致（误差 ≤ 2s）、番茄数仍为 2

**AC-09 本地存储不可用时降级**
- Given 浏览器禁用本地存储（或隐私模式限制）
- When 打开页面并开始计时
- Then 页面正常显示与计时，无报错、不白屏；仅刷新后状态不保留（允许）

**AC-10 跳过阶段**
- Given 专注阶段任意状态
- When 点击「跳过」
- Then 直接进入「短休」，番茄数不增加

**AC-11 后台不跑偏**
- Given 专注阶段运行中
- When 切到其他标签页/锁屏 5 分钟后返回
- Then 剩余时间与真实经过时间一致（误差 ≤ 2s），不出现倒退、重复跳阶段

**AC-12 后台期间阶段已结束**
- Given 专注阶段剩余 10 秒
- When 切到其他标签页停留 30 秒后返回
- Then 已处于「短休」阶段、番茄数 +1、计时器为短休的合理剩余值，不发生多次乱跳

**AC-13 移动端可用**
- Given 360×640 视口
- When 打开页面
- Then 计时器与全部按钮完整可见、可点击，无横向滚动；计时器字号明显大于正文

**AC-14 键盘可用**
- Given 使用键盘
- When 按 Tab 聚焦到主按钮后按 Enter/Space
- Then 计时开始，焦点框可见

**AC-15 子路径资源不 404**
- Given 访问 `/pomodoro-focus/`
- When 打开开发者工具网络面板并强制刷新
- Then 全部请求返回 200（或 304），无 404；将同一页面以 `/pomodoro-focus`（无尾斜杠）访问同样可用或正确重定向

**AC-16 现有站点不受影响**
- Given 上线后
- When 访问 `https://hk.hsddns.com/` 与站点上其他既有路径
- Then 返回码与内容与上线前一致（根路径仍 301）；`nginx -t` 通过

**AC-17 设置改值即存 + 恢复默认（P1）**
- Given 打开设置
- When 将专注时长从 25 改为 10（不点任何保存按钮）
- Then 设置立即生效并持久化：刷新页面后专注时长仍为 10
- And 若当时专注阶段正在运行（进度 40%），改值后当前阶段剩余时间与进度**保持不变**（仍 40%），不跳成 10:00
- When 点「恢复默认」
- Then 专注/短休/长休/长休间隔回到 `25 / 5 / 15 / 4`，且刷新后仍为默认值

**AC-18 页面标题（P1）**
- Given 专注阶段开始
- When 查看标签页标题
- Then 显示形如 `24:59 · 专注`，且随时间更新

| A1 | 单人自用，无账号，数据只存在本机浏览器 | 决定不做后端 |
| A2 | 标准番茄法：专注 25 / 短休 5 / 长休 15、每 4 个长休 | 默认值；P1 可改 |

| A4 | 阶段结束只做站内提示，不做系统通知/声音强制 | 决定不做 Notification |
| A5 | 界面中文，面向个人桌面 + 手机浏览器 | 不做多语言 |
| A6 | 不需要「这个番茄在做什么」的任务输入 | 不做任务清单 |
| A7 | 历史统计（今日/本周）不在首版 | 移到 P2 |

## 6. 风险

| 编号 | 风险 | 影响 | 应对 |
|---|---|---|---|
| R1 | 浏览器后台对定时器节流，倒计时变慢 | 计时不可信 | 以绝对时间差计算剩余（实现交 Arch/Dev），QA 用 AC-11/AC-12 验 |
| R2 | 本地存储被禁用或隐私模式 | 刷新丢状态 | 降级为内存态，不阻断使用（AC-09） |
| R3 | 提示音被浏览器自动播放策略拦截 | 提示失效 | 声音默认关，需用户交互后启用（FR-06b） |
| R4 | 子路径部署导致资源 404 / 白屏 | 页面打不开 | 全部相对路径 + QA 验 AC-15；缓存需版本化 |
| R5 | nginx 改动影响现有站点 | 线上故障 | 只新增 location、不改既有块；先备份 + `nginx -t` + 回滚命令（Ops） |
| R6 | 范围膨胀（想加统计/任务清单） | 延期 | 首版锁死 P0 清单，新增需求走下一版 |
